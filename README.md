# ফারিহার সাথে চ্যাট — Telegram Mini App

## কী কী আছে

- হোম স্ক্রিন (ব্যালেন্স + মেনু)
- কয়েন অর্জন (Monetag প্রাইমারি + Adsterra/Hilltop ব্যাকআপ)
- কয়েন গিফট
- ১-টু-১ চ্যাট (Supabase)
- প্রোফাইল

## সেটআপ

1. `index.html` ফাইলটি GitHub রিপোর **রুট** ফোল্ডারে রাখুন।
2. GitHub Pages চালু করুন (main branch, / root)।
3. BotFather-এ Mini App URL সেট করুন।

## কনফিগারেশন (index.html এর ভিতরে)

const SMARTLINKS = {

## Monetag SDK যোগ করা

Monetag ড্যাশবোর্ড থেকে Rewarded Interstitial ট্যাগ নিয়ে `watchMonetagRewarded()` ফাংশনের ভিতরে বসাতে হবে।

## Supabase টেবিল

আগে থেকে `messages` টেবিল আছে। গিফটের জন্য চাইলে `gifts` টেবিল বানাতে পারেন:

```sql
create table gifts (
  id bigint generated by default as identity primary key,
  user_id bigint,
  user_name text,
  amount int,
  created_at timestamptz default now()
);
```
