# ফারিহার সাথে চ্যাট — v2 (Modular)

## ফাইল স্ট্রাকচার

```
/
├── index.html          ← মূল মিনি অ্যাপ
├── admin.html          ← আলাদা অ্যাডমিন পেজ (ব্রাউজার/মিনি অ্যাপ)
├── css/
│   └── style.css       ← সব স্টাইল
├── js/
│   ├── config.js       ← সেটিংস (আইডি, লিংক, লিমিট, কুলডাউন)
│   └── app.js          ← অ্যাপ লজিক
└── README.md
```

কোনো সমস্যা হলে শুধু নির্দিষ্ট ফাইল রিপ্লেস করুন।

`admin.html` ও শুধু একই আইডি দিয়ে টেলিগ্রাম থেকে খুললে কাজ করবে।

## হেডার ছবি (ফারিয়া)

`js/config.js` এ:

```js
OWNER_PHOTO_URL: "https://your-image-link.jpg",
```

খালি রাখলে অ্যাডমিন লগইন করলে তার টেলিগ্রাম প্রোফাইল ছবি ব্যবহার হবে। অন্য ইউজারদের জন্য ডিফল্ট “ফ” আইকন।

## Monetag

এখনো SDK নেই। পরে `js/config.js` এ Zone ID + `js/app.js` এর `watchMonetagRewarded` আপডেট করবেন।
